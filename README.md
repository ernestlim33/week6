# CPBC enquiry system — course starter

This is the starting point for the new enquiry system for the Community Pro Bono
Centre, built one story at a time in the Applied AI for Law course.

## What is in it

| File | What it is |
|---|---|
| `prd.md` | The PRD for the new system. §5 is the backlog: the stories, in the order we build them |
| `SPRINTS.md` | Your record of each sprint: what you asked for, what you checked, what you found |
| `week5-notes.md` | Your notes from the Week 5 lab and legal close |

There is no system here yet. You build story S1 in the Week 5 lab, into a file called
`index.html`.

## How to use it

1. Click **Use this template**, then **Create a new repository**.
2. Name your copy `week5`. Make it public.
3. Clone your copy onto your laptop, and work there.

All data in this system is synthetic. Never enter a real person's details.
